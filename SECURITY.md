# Security Policy

## Supported Versions

We actively support and apply security patches to the following versions of the Escape Room Password System:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

We take the security of our application seriously. If you find any security vulnerabilities (such as package dependencies bugs, potential XSS inputs, or leaks), please do not report them via public GitHub issues.

Instead, please follow these steps to report the issue responsibly:

1. Email a detailed description of the vulnerability to **security@lakescorp.com** (placeholder).
2. Include the following details in your report:
   - Type of vulnerability (e.g., XSS, dependency issue).
   - Step-by-step instructions to reproduce the issue.
   - Any potential impact or mitigation strategy.
3. We will acknowledge receipt of your vulnerability report within 48 hours and work with you to resolve it in a timely manner.

Thank you for helping keep this project secure!
